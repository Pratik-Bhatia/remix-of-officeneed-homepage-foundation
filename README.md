# OfficeNeed Homepage Foundation

Build ONLY the Navbar and Hero Section for the new OfficeNeed Shopify storefront homepage.

Do not modify or create other homepage sections yet.

I will attach the official OfficeNeed logo with this prompt. Use the attached logo as the ONLY logo asset. Do not recreate, redraw, recolor, distort, or replace the logo.

==================================================

DESIGN DIRECTION

==================================================

The design should take inspiration from the structure and presentation quality of Apple's website.

IMPORTANT:

Do NOT copy Apple's website, layout, typography, colors, imagery, or branding directly.

Instead, take inspiration from Apple's design principles:

- Minimal and premium

- Strong visual hierarchy

- Generous whitespace

- Product/category-led navigation

- Clear typography

- Large editorial-style hero

- Simple navigation

- Strong visual storytelling

- High-quality product imagery

- Subtle interactions

- Content that encourages exploration

The final design must feel like an original OfficeNeed experience, not an Apple clone.

The overall visual language should communicate:

- Professional

- Premium

- Modern

- Enterprise-grade

- Trustworthy

- Clean

- Sophisticated

Avoid anything that makes the website feel like a generic local ecommerce website or a template-based Shopify store.

==================================================

NAVIGATION

==================================================

Create a responsive global navigation/header.

Desktop navigation should include:

[OfficeNeed Logo]

Corporate Gifting

Office Stationery

IT Infrastructure

Printing & Branding

Fragrance & Luxury Gifting

OfficeNeed Exclusive

Utility actions:

Search

Account

Cart

Corporate Gifting is the highest-priority category and should receive slightly stronger visual emphasis without making the navigation visually unbalanced.

The navigation should remain clean and restrained.

Do not overcrowd the header.

Use appropriate spacing between navigation items.

The header should have:

- Proper horizontal alignment

- Consistent vertical rhythm

- Clear hover states

- Accessible focus states

- Smooth interaction transitions

- Sticky positioning if appropriate for the design

==================================================

NAVIGATION BEHAVIOUR

==================================================

Use a professional ecommerce navigation pattern.

For desktop:

Hovering or clicking major categories can reveal a clean mega-menu / dropdown.

The mega-menu should be designed as an exploration tool rather than a simple list.

For example:

Corporate Gifting

    Gift Sets

    Corporate Gifts

    Premium Gifts

    Drinkware & Utensils

    Customized Gifts

Office Stationery

    Writing Instruments

    Notebooks

    Desk Accessories

    Office Supplies

IT Infrastructure

    Mouse

    Keyboards

    Mousepads

    Printers

    Computer Accessories

Printing & Branding

    Custom Printing

    Corporate Branding

    Printed Materials

    Branded Merchandise

Fragrance & Luxury Gifting

    Perfumes

    Fragrances

    Premium Gifts

    Luxury Gifting

OfficeNeed Exclusive

    Exclusive Products

    Featured Exclusives

    New Exclusives

Keep the mega-menu visually minimal and easy to scan.

Do not make it excessively large.

==================================================

MOBILE NAVIGATION

==================================================

The navigation MUST be fully responsive.

On mobile:

- Use the OfficeNeed logo

- Use Search

- Use Cart

- Use a hamburger/menu button

- Hide the full desktop navigation

- Open a full-screen or highly polished mobile navigation drawer

- Categories should be expandable/collapsible

- Maintain clear hierarchy between category and subcategory

- Ensure touch targets are comfortably sized

- Avoid horizontal scrolling

The mobile navigation should feel intentionally designed, not like a compressed desktop navigation.

==================================================

HERO SECTION

==================================================

Create a large, premium editorial-style hero section directly below the navigation.

The hero should communicate the core OfficeNeed positioning:

"One Vendor. Multiple Solutions."

Supporting message:

"Corporate procurement made simpler."

Primary CTA:

"Explore Solutions"

Secondary CTA:

"Shop Products"

The hero should introduce OfficeNeed as a complete business procurement partner rather than simply another online store.

The visual direction should be similar in PRINCIPLE to Apple's category/product storytelling:

- Large headline

- Short supporting copy

- Minimal CTA group

- Strong visual composition

- Large high-quality imagery

- Generous whitespace

- Clear focal point

- Premium presentation

Do not copy Apple's exact hero composition.

==================================================

HERO VISUAL

==================================================

Create a visually strong hero using OfficeNeed's actual business categories as the visual storytelling foundation.

The hero should communicate that OfficeNeed brings multiple business solutions together under one platform.

Visually incorporate products or visual cues representing:

- Corporate Gifting

- Office Stationery

- IT Infrastructure

- Printing & Branding

- Fragrance / Luxury Gifting

Corporate Gifting should have the strongest visual presence because it is OfficeNeed's highest-priority category.

The composition should feel curated and premium rather than like a random product collage.

Avoid:

- Generic stock-office imagery

- Cheap ecommerce banners

- Overcrowded product grids

- Excessive text

- Generic gradients

- Excessive glassmorphism

- Overuse of animations

- Visually noisy backgrounds

The imagery should have strong clarity, sharpness, and premium product presentation.

==================================================

HERO LAYOUT

==================================================

Desktop:

Use a large, immersive hero composition with:

Headline

Supporting copy

CTA buttons

Large visual/product storytelling area

The hero should occupy a significant portion of the initial viewport without creating unnecessary vertical scrolling.

Maintain strong visual hierarchy:

1. OfficeNeed positioning

2. Supporting message

3. Primary CTA

4. Secondary CTA

5. Supporting visual

Mobile:

Do NOT simply shrink the desktop layout.

Create a dedicated responsive composition.

The hierarchy should become:

One Vendor.

Multiple Solutions.

Corporate procurement made simpler.

[Explore Solutions]

[Shop Products]

Then the visual.

Ensure the headline wraps naturally and does not produce awkward line breaks.

The hero should remain visually impactful while fitting comfortably within a mobile viewport.

==================================================

RESPONSIVE REQUIREMENTS

==================================================

Design and implement the section for:

- Large desktop

- Standard desktop

- Tablet

- Mobile

- Small mobile

Use responsive breakpoints appropriately.

Check:

- Navigation spacing

- Typography scaling

- Hero height

- Image scaling

- CTA stacking

- Text wrapping

- Touch target sizes

- Horizontal overflow

- Safe spacing around screen edges

There must be NO horizontal scrolling at any viewport width.

==================================================

INTERACTION & MOTION

==================================================

Keep motion subtle and premium.

Possible interactions:

- Navigation hover transitions

- Mega-menu reveal

- CTA hover states

- Very subtle hero image movement

- Gentle entrance animation

Avoid excessive animations.

The design should still feel premium with animations disabled.

Respect:

prefers-reduced-motion

==================================================

ACCESSIBILITY

==================================================

Implement proper:

- Semantic HTML

- Heading hierarchy

- Navigation landmarks

- Accessible buttons

- Keyboard navigation

- Visible focus states

- Appropriate aria-labels for icon-only buttons

- Sufficient color contrast

- Alt text for meaningful images

The hero should use a proper H1.

==================================================

PERFORMANCE

==================================================

Because this is an ecommerce homepage:

- Do not load unnecessarily large images

- Use responsive image sizing

- Avoid excessive JavaScript

- Avoid unnecessary animation libraries

- Lazy-load imagery that is not immediately visible

- Keep the hero's primary visual optimized for fast loading

- Prevent layout shift by reserving image dimensions

==================================================

DESIGN SYSTEM

==================================================

Establish a small reusable foundation for this section:

- Typography scale

- Heading styles

- Body text

- Button styles

- Navigation styles

- Spacing system

- Border radius

- Icon sizing

- Responsive breakpoints

Do not introduce excessive design tokens or unnecessary complexity.

The design system should be reusable when we build the remaining homepage sections.

==================================================

IMPORTANT CONSTRAINTS

==================================================

1. Use the attached official OfficeNeed logo.

2. Do not modify the logo.

3. Do not use Apple's logo or Apple branding.

4. Do not copy Apple's exact layout.

5. Use Apple's website only as inspiration for premium ecommerce storytelling and category-led navigation.

6. Do not build the remaining homepage sections.

7. Do not modify existing unrelated pages or components.

8. Keep the implementation modular so the remaining homepage can be built around this foundation later.

9. Do not push code to Git.

10. Do not replace existing assets unless explicitly instructed.

11. If suitable hero imagery does not exist, use a temporary clearly identifiable placeholder rather than generating unrelated stock imagery.

12. Make the entire implementation production-quality and responsive.

==================================================

SUCCESS CRITERIA

==================================================

The result should immediately communicate:

"OfficeNeed is a premium, professional corporate procurement platform."

The first viewport should make it clear:

What OfficeNeed is

→ What it offers

→ Why it is relevant

→ Where the user can explore next

The experience should feel closer to a premium modern commerce brand than a conventional catalogue/ecommerce website.
